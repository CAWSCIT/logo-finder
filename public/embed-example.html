Embedding the C.A. logo browser

Paste these two lines wherever the logos should appear. Everything below the line is rendered by that snippet. 

<div id="ca-logo-app"></div>
<script src="https://cawscit.github.io/logo-finder/build.js"></script>

The widget renders inside a Shadow DOM, so the host page's CSS cannot restyle it and its CSS cannot leak out. Logos, thumbnails and PDFs are loaded from wherever build.js was served from.
